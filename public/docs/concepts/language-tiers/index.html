Language tiers

Every verb runs as a WebAssembly component in one sandbox. What differs is how it gets there. You can bring a compiled component, or upload JavaScript or Python source that the host interprets inside a shared runner component.

TierYou uploadNeeds a toolchainWho runs it
Componenta .wasm built for wasm32-wasip2yesthe component itself
JavaScripta .js source filenothe shared QuickJS runner
Pythona .py source filenothe shared monty runner

The upload names its language with the ?lang= query parameter on POST /v1/modules (lang=text/javascript or lang=text/x-python), or with the Content-Type header on a PUT to …:verb/code. A server accepts only the languages in service.acceptedSourceLanguages in discovery. A language the server does not offer returns 415 unsupported-language. On POST /v1/modules, a body that is not WebAssembly and has no ?lang= is read as a component and fails with 400 invalid-component, whatever its Content-Type.

Components

Section titled “Components”

Any language that compiles to a WASI 0.2 component can write a verb. Rust is the reference path, with an SDK crate (sdk/rust/) that hides the binding boilerplate. The component targets a WIT world, and that world is its capability list. The host rejects imports outside the offered interfaces at upload. Components get the full capability surface with per-verb enforcement, and they handle binary input and output. See Write verbs in Rust.

JavaScript

Section titled “JavaScript”

A JavaScript verb defines function invoke(input). The host stores the source and, on each request, passes it with the request input to one trusted QuickJS runner component. Nothing is compiled per upload, so the host has no compiler to attack.

The runner exposes the host capabilities as globals: log, compose, publish, obj (get, set, getAt, setAt, setAtIf, query, path, shape, shapeAt), llm and caller (subject, isAnonymous, roles, scopes, groups, claim). The runner caps its heap at 24 MiB and its stack at 512 KiB, below the host limits. A script that recurses without end overflows the stack and the request fails with 500 and restact_code: trap; the host is unaffected. A source that does not parse is rejected at upload with 422. See Write verbs in JavaScript.

Python

Section titled “Python”

A Python verb defines def invoke(input). It is interpreted by monty, a Python interpreter written in Rust, embedded in a runner component. monty implements a subset of the language, and the runner narrows it further:

  • log, compose and publish are functions. obj, llm and caller are host-provided objects in snake_case: obj.get, get_bytes, get_bytes_at, set, get_at, set_at, remove, remove_at, shape, shape_at, set_at_if, path, query, llm.complete and caller.subject, is_anonymous, roles, scopes, groups, claim, actor, invoker. obj.query takes keyword arguments and returns a page object, with the same fields as the JavaScript page in snake_case.
  • Input is a str. Return a string, or a dict or list that is serialised as JSON; None gives an empty body.

What runs, checked against the pinned runner:

  • Works: functions, lambdas, default arguments, *args and **kwargs parameters, decorators, global and nonlocal, comprehensions (list, dict, set) and generator expressions, f-strings with format specs and !r, try/except/else/finally, raise ... from, assert, the walrus operator, type annotations, slicing, big integers, and async def with await, asyncio.run and asyncio.gather.
  • Also works: class definitions, % formatting and str.format.
  • Rejected at upload with 422 invalid-source: generator functions (yield) and other unsupported statements such as del, class inheritance and async for/async with. match statements and dataclass field work.
  • Imports: json, re, math, sys, typing, asyncio, collections, itertools, functools, datetime values and random after an explicit random.seed(n), hashlib (digests, not file_digest or scrypt), csv, bisect, tomllib, decimal and the string functions of os.path work. The clock and sleep (time.time, time.sleep, datetime.datetime.now), unseeded random, open, directory listing, os.path existence and stat checks, path resolution (os.path.realpath) and environment reads fail with script-error: unsupported operation (os/filesystem). Other modules, for example socket and subprocess, fail with a catchable ModuleNotFoundError. There are no third-party packages.
  • eval() and exec() run inside the same sandbox, with the script’s own names and limits. Never pass caller input to them: the code would run with the verb’s authority, including runs_as=owner.
  • Exceptions: you can catch builtin exceptions, including RecursionError. An uncaught one returns 422 script-error with the traceback.
  • Limits: recursion is capped at 1000 frames and the heap at 24 MiB. Exceeding the heap raises MemoryError.

A source that does not parse is rejected at upload with 422. See Write verbs in Python.

Shared properties of the script tiers

Section titled “Shared properties of the script tiers”
  • Input arrives as text. A string output passes through, an object or list is serialised as JSON, and a JavaScript Uint8Array or ArrayBuffer or a Python bytes is sent as raw bytes. A script can read a stored binary value up to 6 MiB with obj.getBytes() (JavaScript) or obj.get_bytes() (Python). For anything larger, or for heavy transforms of the bytes, use a compiled verb.
  • An uncaught error becomes a script-error whose message is returned to the caller. Do not put secrets in error messages.
  • The script is parsed on each invocation. Keep scripts small.
  • Both runners are part of the trusted computing base. Every script verb shares one runner, so capability checks happen in the host at run time, not through a per-verb import list. See the Security model.
  • A runner is optional. A server started without one omits that language from discovery.

Choosing a tier

Section titled “Choosing a tier”

Use JavaScript or Python for glue logic, data shaping and quick iteration: you can upload with curl and edit in place. Use a component when you need binary data, a language with a mature ecosystem, or the tightest control over which interfaces the verb imports. A script and a component can call each other with compose; the caller cannot tell which tier a callee uses.
