Write verbs in JavaScript

Upload a JavaScript file and call it over HTTP. There is no toolchain and no build step: the host stores your source and runs it in a shared QuickJS runner inside the same sandbox, with the same limits and capability checks as a compiled verb.

This guide takes you from a one-line function to an action that reads and writes object data, reads its caller, and calls another verb. For the full list of globals and the reasoning behind them, see the authoring reference.

Prerequisites

Section titled “Prerequisites”
  • A running restactd with the JavaScript tier enabled. Install shows how to build the runner; a host without it answers 415 to a JavaScript upload.
  • curl, and a shell. Commands use localhost:8080; the -g flag stops curl from treating {id} as a glob.

Check that the host accepts JavaScript:

A function you can call with GET

Section titled “A function you can call with GET”

A verb is a function or an action. A function has no side effects, is called with GET, and its responses can be cached. An action may write data and is called with POST. You choose the kind at deploy time.

  1. Write the verb. It defines invoke(input), where input is the request body or ?input= value as a string.

  2. Deploy it. The lang parameter names the source language, and verb is the route.

    The host parses the script before it answers. The 201 body lists the imports the verb ended up with and its content hash.

  3. Call it.

    A request body works too: curl -g -X GET --data-binary 'Grace' localhost:8080/v1/greet:hello.

  4. Try the wrong method. The host enforces the function/action split.

What just happened: greet:hello is a route with no object in front of it (a collection verb). The script’s return value became the response body. log wrote a structured record to the host’s log, where it appears as [guest greet:hello log info] greeting Ada.

Return structured data

Section titled “Return structured data”

A string passes through unchanged. An object or array is serialized with JSON.stringify. null and undefined give an empty body. The input is always text. A Uint8Array or ArrayBuffer return value is sent as raw bytes. To accept binary input, use a Rust verb.

An action that uses object data

Section titled “An action that uses object data”

An entity verb is bound to an object: the route pages/{id}:view runs against pages/home, pages/about and any other pages/<name>. Inside the script, obj reads and writes that object’s data.

The deploy URL spells {id} as %7Bid%7D so the query string stays valid. The -g flag stops curl from treating braces as a glob in the other commands.

Property values are typed. obj.get returns undefined when the property is absent or the caller may not read it. If you declare kind=function, the host refuses the write: functions may read object data but not change it (403, forbidden-side-effect).

Typed values. A property holds a string or a JSON value, and the runner maps them at the boundary:

a stringtextthe same string (the string "5" stays a string)
a number, boolean, array or objectjson (via JSON.stringify)the JSON.parsed value
undefined or nullrefused: invalid-input (422); use obj.removen/a

For obj.setAtIf, expected maps the same way, and null or undefined means “absent”. Query rows carry the same typed properties and orderValue.

The obj object has these methods:

MethodDoes
obj.get(name), obj.set(name, value)Read or write a property of the bound object.
obj.getAt(path, name), obj.setAt(path, name, value)Read or write a property of another object, checked against the caller’s permissions.
obj.remove(name), obj.removeAt(path, name)Remove a property of the bound object or of another object, checked against the caller’s permissions like a write. Removing an unset property succeeds. remove throws not-found when the bound object holds no data, and removeAt throws not-found when no object is stored at path.
obj.setAtIf(path, name, value, expected)Write only if the current value equals expected (null means “absent”). Throws precondition-failed otherwise.
obj.shape(), obj.shapeAt(path){properties, children, verbs} that the caller can see.
obj.path()The concrete path the verb was invoked on, for example pages/home.
obj.getBytes(), obj.getBytesAt(path)The binary value of the bound or another object as {contentType, data} with data a Uint8Array, or undefined when there is none.
obj.query(options)A page of objects under a path prefix. See Store and query object data.

Read the caller

Section titled “Read the caller”

caller describes who made the request. It grants no authority; it reports the identity the verb already runs under.

On a host with no authentication configured, every caller is anonymous and the answer is {"anonymous":true,"roles":[],"scopes":[],"groups":[]}. Absent values are undefined, so JSON.stringify leaves them out. With a bearer token for alice that carries roles: ["editor"] and dept: "eng":

What the runner provides and what it does not

Section titled “What the runner provides and what it does not”
AvailableNot available
Modern ECMAScript (arrow functions, destructuring, template strings, optional chaining), JSON, Math, Date, Map, Set, RegExp, BigInt, typed arrays, atob/btoa, encodeURIComponentfetch, XMLHttpRequest, sockets, a filesystem
log, console.log, compose, obj, caller, publish(topic, name, data) (events, when the verb has the event grant), llm.complete(request) (messages take the role "user" or "assistant", and the host refuses any other; only when the host has an llm connector configured, and not in a function)setTimeout, require, ES import, TextEncoder, structuredClone
Synchronous codeAwaiting: an async function returns a promise, which is serialized as {}

Every invocation runs under per-request limits, which discovery reports under defaultCapabilities: 200 million compute units, 2 seconds of wall-clock time and 32 MiB of memory by default. The runner also caps its own heap at 24 MiB.

  • A script that runs out of compute is stopped with 429 and restact_code: cpu-budget. A tight while (true) {} hits this in a fraction of a second.
  • A script that allocates past the heap cap fails with script-error and Error: out of memory.
  • Wall-clock overruns are 408; memory overruns at the sandbox level are 507.

Source is parsed on every invocation, out of the run fuel, so keep hot scripts small and give a large source a higher ?fuel= (see Capabilities and budgets). The runner is a single trusted component shared by every JavaScript verb; what a script can reach is decided by the host’s grants, ACLs and policy, not by the script.

Editor completion and type checks

Section titled “Editor completion and type checks”

The runner installs obj, caller, log, compose, publish, llm and console as globals, so an editor reports them as undefined. sdk/js/restact.d.ts declares them. Copy it next to your verb and add /// <reference path="restact.d.ts" />, or list it in tsconfig.json with checkJs on. sdk/README.md has the config.

The file declares what the runner exposes through the host. It does not declare atob, btoa, performance or queueMicrotask, which the QuickJS engine provides (see the table above). If a verb uses one, add your own declaration.
