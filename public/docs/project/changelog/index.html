Changelog

All notable changes to this project are recorded here. The format follows Keep a Changelog.

[Unreleased]

Section titled “[Unreleased]”

Added

Section titled “Added”
  • Verb input and output schemas (feature verb-schemas). POST /v1/modules takes input_schema and output_schema, each the percent-encoded JSON text of a self-contained JSON Schema 2020-12 document of at most 8 KiB (no $id or anchors, $ref only as #/... pointers that resolve to a subschema, legacy definitions refused; a violation is 400 invalid-input naming the parameter and node). They are advisory (never enforced), carried unredacted as inputSchema and outputSchema in discovery, :meta and x-restact-verb, re-declared by every POST and preserved by PUT :verb/code and rollback. /openapi.json emits each declared schema once under components.schemas and references it from the request body, the 200 response and a function’s ?input= parameter; a verb declaring none is unchanged. restact deploy gains --input-schema FILE and --output-schema FILE (exit 3 against a host without the token), and the restact mcp bridge types a tool from the verb’s own schemas, wrapping a non-object input as {input: ...}, and deploy_verb takes input_schema/output_schema.
  • Typed property values (feature typed-values). A property value is any JSON value, not only a string: the data plane stores and returns numbers, booleans, arrays and objects as sent, and a top-level null still removes. Numbers follow I-JSON (finite, whole numbers within ±(2^53−1), else 400 invalid-input), nesting is capped at 64 levels, $policy may be sent as an object, and the ETag is over the RFC 8785 canonical form (unchanged for an all-string object). filter=key=literal matches a string byte-for-byte or a non-string by canonical JSON, and a keyset order puts strings before numbers, booleans, arrays and objects. The object WIT interface carries a property-value { text, json }; obj.get/obj.set in JavaScript and Python are typed, restact-sdk gains PropertyValue and an optional json feature, and NativeCtx gains get_value/set_value/get_value_at/set_value_at. Redeploy every stored script verb after upgrading: a verb stored with the previous runner answers 500 verb-unlinkable.
  • A property can be removed. A null member in a PUT body removes that property (feature put-null-removes), and the object interface gains remove and remove-at (feature object-remove), with obj.remove/obj.removeAt in JavaScript and obj.remove/obj.remove_at in Python. Removal needs the authority that sets the property: a set final property answers 409 property-final, $owner and the $ attributes other than $policy cannot be removed, and removing $policy needs the authority to rewrite it. Removing a property that is not set changes nothing.
  • A tag-driven release workflow (.github/workflows/release.yml) builds tarballs for Linux x86_64 and aarch64 and macOS, a runners tarball and checksums.txt, attests them, and publishes the GitHub release after approval of the release environment, in the public repository only. make release-local builds the tarballs locally and make release-images builds the images from them.
  • Released container images at ghcr.io/stackumi/restactd, built from the tarball binaries: a slim image (X.Y.Z, X.Y, latest) and a -full image with PostgreSQL, OpenBao and OpenTelemetry (X.Y.Z-full, X.Y-full, full). Each is built twice and compared by digest before it is smoked and pushed. The slim image refuses RESTACT_DATABASE_URL and names -full. docker.yml is a manual build check and no longer publishes.
  • An installed restactd finds its script runners without configuration. A binary whose directory has a sibling share/restactd/ takes runners/js_runner.wasm and runners/py_runner.wasm from there, never from its working directory, and seeds no demo, example or docs content unless the matching variable is set; any other binary keeps the working-directory defaults. RESTACT_{JS,PY}_RUNNER_WASM=off turns a tier off, an explicit path that cannot be registered withdraws the tier (discovery drops it, new deploys return 415, deployed verbs keep running), and the boot prints layout:, javascript: and python: lines. A release build bakes the runner hashes in (RESTACT_BUILD_{JS,PY}_RUNNER_SHA, shown in --version), so a swapped runner leaves the tier off.
  • restact-sdk is packaged for crates.io: package metadata and a README, docs.rs settings for wasm32-wasip2, a cargo publish --dry-run check in CI that also builds word-count-sdk and summarize-sdk from the packed crate, and examples/obj-probe-sdk covering the object and event worlds.
  • restactd reown --from S --to S --path P [--subtree] [--dry-run] [--yes] [--json] [--no-secrets] moves the verbs and objects one subject owns to another, offline, through the same engine as POST /admin/reown. It takes the data-directory lock on a filesystem store (a dry run takes none) and runs as one more node on PostgreSQL. It refuses without a secrets mount setting unless --no-secrets is passed.
  • restactd audit ancestry lists, read-only and without a lock or listener, the claimed ancestors, the same-level pattern pairs whose winner changed when same-level precedence stopped depending on deploy order, and the orphan definitions a store holds, so it runs beside a live server. Exit 0 with no findings, 3 with findings, 1 when it cannot complete, 2 for usage or a directory that is not a store root. It reads the ancestor-claim guard switch from its own environment (claims and orphans are listed only when the guard is on; orphans only under a coupled binding mode), lists what the host’s own bootstrap wrote as host-bootstrap without counting it, needs no page-token key and creates nothing. A host with changed pairs prints one warning: boot line naming the command, after it starts serving.
  • RESTACT_QUOTA_OBJECTS caps the objects each owner holds. Unset or off means no cap, a whole number is the cap, and any other value refuses boot. A creation over the cap answers 429 with code quota and no Retry-After; updates, deletes and owner changes are never refused. PostgreSQL counts across the cluster (migration 0009_object_counts.sql), a filesystem host rebuilds its counts at boot, and the boot summary shows objects=.
  • restactd checkpoint [--out DIR] [--token-stdin] [--timeout D] [--json] writes a verified snapshot of the filesystem store, offline under the data-directory lock or through POST /admin/checkpoint on a running server, and restactd restore --from DIR [--json] replaces a stopped host’s store with a snapshot, keeping the previous state in pre-restore-<time>/. A live snapshot is copied index files first, then state/, then blobs/, so it never names a blob it lacks, and a FIFO, socket, device or symlink inside the store is refused. A snapshot is written into a .partial- directory and takes its name once whole. The live path sends to one IP-literal RESTACT_BIND address, and only while the lock file reads server. An interrupted restore is rolled back from its {ts, from} marker without deleting an original.
  • A filesystem host takes an exclusive lock on <data-dir>/locks/data-dir.lock and refuses to start when another process holds the directory. A directory with a RESTORE-IN-PROGRESS.json marker also refuses to start.
  • restactd healthcheck [--ready] [--timeout D] probes /healthz or /readyz on the RESTACT_BIND address. The container HEALTHCHECK uses it and the runtime image no longer installs curl.
  • restactd token mint --sub S [--role R] [--group G] [--scope S] [--claim K=V] [--ttl D] [--json] signs an HS256 bearer token with the RESTACT_JWT_SECRET in the environment.
  • Script verbs: Python gains llm.complete, and both script tiers read stored binary values with obj.getBytes()/obj.get_bytes() (capped at 6 MiB); a JavaScript verb can return a Uint8Array or ArrayBuffer as the response bytes.
  • Editor types for script verbs: sdk/js/restact.d.ts and sdk/python/restact.pyi, checked against wit/ and the runners by make check-verb-types.
  • The restact command line: a skeleton with context add|use|ls|rm|show and discover, exit codes by failure class, --json output, and a config and credentials file that refuses unsafe permissions. The HTTP client core it shares with the MCP bridge now lives in the restact library crate.
  • restact mcp runs the MCP bridge from the restact binary and takes its host and token from the selected context when no RESTACT_MCP_* target variable is set. The separate restact-mcp binary is gone, and the plugin bootstrap and release assets use restact (restact-<tag>-<target>.tar.gz).
  • restact deploy, call, ls verbs|objects, get, put and rm: deploy a JavaScript, Python or Wasm verb (--lib FILE, repeatable, prepends shared library files to a script verb), call a verb with the method taken from discovery, list and read and write objects, and remove objects or verbs. Uploads and listings stay within --max-bytes, binary output is not written to a terminal without -o, and rm asks for confirmation only when stdin and stderr are terminals, so a script must pass --yes.
  • restact history and rollback (a row number or a hash prefix, sent with If-Match from the code tag), restact events tail (reconnects with Last-Event-ID, an idle timeout, Ctrl-C exits 130, --json prints one event per line), and restact admin reset|checkpoint|reown.
  • restact mcp exits 2 for every configuration error, including a local RESTACT_MCP_OPENAPI file that cannot be read or parsed, as the exit codes say for a usage or local configuration error. An OpenAPI URL in a log line has its credentials, query and fragment removed, whatever the case of its scheme, and text from the OpenAPI document or from discovery is cleaned of control characters before it is logged.
  • restact mcp refuses a non-loopback http:// target in RESTACT_MCP_HOST_URL or RESTACT_MCP_HOSTS (exit 2, naming the entry) when it would send that target a token, either a bearer or RESTACT_MCP_LISTEN’s forwarded client bearers. RESTACT_MCP_ALLOW_PLAINTEXT=1 accepts the risk. Every explicit target value must be an http or https URL with a host and no credentials, query or fragment, with or without a token; otherwise startup exits 2, and a malformed RESTACT_MCP_HOSTS entry is named by position, never quoted.
  • restact call and the bridge’s invoke_verb refuse a route that discovery lists twice with different kinds, as the same route or as two equally specific templates: restact call exits 2 and asks for --get or --post, and the bridge returns a tool error naming both entries.
  • Each log and warning line restact mcp writes to stderr starts with restact mcp:; a refusal prints restact mcp: <reason> and exits with the CLI’s usual code.
  • The restact mcp switches RESTACT_MCP_ALLOW_DEPLOY, _DATA_WRITES, _VERB_ADMIN and _REGISTRATIONS accept 1/true/on/yes and 0/false/off/no; any other value exits 2 naming the variable.
  • make check-env-namespaces fails when the host and the restact crate read the same RESTACT_* name, or when the host reads a RESTACT_MCP_* name other than RESTACT_MCP.

Changed

Section titled “Changed”
  • The restact and restactd libraries no longer install a process-wide rustls crypto provider. Each HTTP client they build, including the OTLP exporters, carries its own ring configuration and still verifies https against the system trust store, so an embedding application may install any provider of its own. restact::host::ensure_tls_provider is removed.
  • A property or declaration name beginning @ is reserved, as one beginning $ is. A data-plane PUT with an @ member (a null one included) answers 400 invalid-input and stores nothing, a secrets-mount PUT refuses an @ member beside value, a declaration named @x is refused on PUT …/props and ignored when a stored one is loaded, and reads, listings, get, get-at and query never return one. Verb refusals of a reserved name say it is in a reserved namespace.
  • An object path with a . or .. segment, literal or percent-encoded, is refused 400 invalid-input on every data-plane method (including OPTIONS and PATCH), on :verb invocation and in the GET /v1 prefix, before any 404 or 405, and the body does not echo the path. A verb’s object calls and native verbs refuse it as they refuse an @ segment. Other names with dots (a.b, ..., .hidden, x..y) are valid. Deploying a verb under such a path or an @ segment, invoking a :verb or using a management route under an @ segment, and a schedule or subscription target with either, are refused 400. A compose target with one answers as a target that resolves to no verb. An invocation on a path with an empty segment (/v1/a//b:go, /v1/a/b/:go) answers 404 instead of running bound to the non-canonical path, and a GET on such a path no longer reaches an accessor.
  • Breaking: the runtime image is gcr.io/distroless/cc-debian13:nonroot (Debian 13, no shell, no package manager) and runs as uid and gid 65532 in place of uid 10001; the builder is rust:1.99.1-trixie. An existing /data owned by uid 10001, whether a named volume first filled by the old image (such as make docker-run’s restact-data) or a bind mount, now fails to start with an unwritable-data-directory error. Move its ownership once: chown -R 65532:65532 <dir> for a bind mount, or docker run --rm -v <vol>:/data busybox:1.38.0@sha256:fd7dc98638c8e305f4dc34e979f1c0fdfdcaeb0fbf8fcff77ae834b6da3d7e6e chown -R 65532:65532 /data for a named volume. A fresh, empty volume needs nothing, because Docker copies the image’s ownership only into an empty volume. docker exec <container> sh no longer works; use restactd subcommands through docker exec, a --pid/--network sidecar container, or the local-only make docker-build-debug image, which replaces make docker-shell. The compile cache moves to /home/nonroot/.cache/restactd.
  • RESTACT_EXAMPLES=1 seeds a fixed list of docs pages (README, architecture, authoring-verbs, building-applications, cli, configuration, development, http-api) instead of every .md file in RESTACT_DOCS_DIR, and scripts/seed-docs.sh seeds the same list. A data directory seeded before this change keeps the docs/* objects of pages no longer on the list, and they belong to anonymous. Without auth, remove each with DELETE /v1/docs/<page>. With auth, move each to an operator first and delete it as that operator: stop the server and run restactd reown --from anonymous --to <operator> --path docs/<page> --no-secrets --yes (drop --no-secrets and set the server’s secrets settings if it has a mount), or run restact admin reown with the same flags against a server that has RESTACT_ADMIN_REOWN set.
  • With RESTACT_BUILTIN_SITE=1 (or HostBuilder::with_builtin_site()) the repo_doc fallback no longer serves spec/, so a /spec/… request answers 404. The built-in site links nothing there. The Docker image no longer copies spec/ into /app.
  • The host runs on wasmtime 50.0.1. Compiled-component cache entries are keyed by the wasmtime version, so the first start after upgrading compiles every component again into a new cache directory, and the previous version’s directory is swept once its newest entry is 30 days old. Instantiating a component now charges fuel for each operator in its global initializers; verbs and capabilities otherwise behave as before.
  • restact and restact mcp send no RESTACT_TOKEN (and the bridge no RESTACT_MCP_BEARER) to the built-in http://127.0.0.1:8080 used when no server was chosen, since another local process may hold that address. One line on stderr names the variable held back and says to set RESTACT_URL. A server written out, including http://127.0.0.1:8080, still gets the token. restact mcp with RESTACT_MCP_LISTEN and no chosen server exits 2, since each HTTP client’s own bearer would be forwarded to that unchosen address.
  • The restact-client bootstrap uses the Apple-silicon prebuilt under a Rosetta shell, and its no-cargo message points to RESTACT_MCP_BOOTSTRAP_BIN.
  • The Python tier moves to monty 1.4.0. match statements, dataclass field, hashlib (digests), the os.path string functions, csv, bisect, tomllib and decimal now work; yield and the other unsupported statements (del, class inheritance, async for/async with) are still refused at upload. An unknown import raises a catchable ModuleNotFoundError, so try: import x / except ImportError works; every other OS call is still an uncatchable unsupported operation (os/filesystem). The runner’s content hash changes, so an operator who pins RESTACT_PY_RUNNER_SHA must re-pin it to the hash scripts/build-py-runner.sh prints.
  • The PostgreSQL event log is bounded at every insert: RESTACT_PG_EVENT_LOG_MAX_BYTES (default 64 MiB) and a now-hard RESTACT_PG_EVENT_LOG_CAP both hold, the oldest events go first, and boot refuses a junk, zero or too-small value naming the variable (migration 0010_event_log_bounds.sql). A resume past trimmed events, a node catching up below the trim point, a failed replay query or a reset gets a gap event (missed is omitted when the count is unknown), and event sequence numbers commit in order so delivery never skips a late commit.
  • restact-sdk generates its bindings in build.rs on wit-bindgen 0.63 instead of generate! on a pinned 0.44; the built components’ imports and exports are unchanged.
  • Operator log escaping treats Unicode format characters (bidi controls, zero-width characters, the soft hyphen) like control characters, so they cannot reorder or hide text in a log viewer.
  • Executor::object_put_blob and RouteExecutor::object_put_blob (a custom route’s rc.exec) refuse a blob with invalid-input unless a non-empty content type is exactly one media type (an empty one is stored as application/octet-stream), the same test the data plane applies.
  • A coupled DELETE of an object removes every definition anchored at it as the store lists them, and the check that refuses creating an ancestor of a foreign object or definition reads definitions from the store too, so a definition another node deployed counts before this node has loaded it. Creating a secrets mount commits the backend value and the object’s reference together: if the reference write fails, the value just written is purged and the original error is returned. PostgreSQL gains an index on deployments.route for the prefix listing.
  • On PostgreSQL a schedule or subscription deleted on another node no longer fires once the DELETE has returned 204: each firing reads the registration’s row by primary key just before it starts. The registration listener reloads all registrations when its connection is re-established, and the periodic reconcile (RESTACT_PG_RESYNC_INTERVAL_SECS) reloads them too.
  • Deploy-time validation is charged to the caller’s fuel quota for the fuel it consumed (at least the flat deploy cost), whether the deploy, code replace, rollback or re-validating policy write succeeds or is refused; a request refused before validation runs stays free.
  • POST /admin/reset and every checkpoint share one admin-operation lock: one that finds the other running is refused 409 (conflict) instead of a reset deleting blobs under a live copy, an interval tick that finds the lock held is skipped, POST /admin/checkpoint is exempt from RESTACT_REQUEST_TIMEOUT_MS, a checkpoint’s copy finishes even when its client gives up, and shutdown waits for a running copy.
  • A RESTACT_ISOLATION value other than process, an empty one included, refuses to start (exit 1); only an unset variable runs in-process.
  • RESTACT_ISOLATION=process with neither RESTACT_DATA_DIR nor RESTACT_DATABASE_URL refuses to start (exit 1), with one line naming all three variables.
  • A RESTACT_BIND host name that resolves to more than one address, such as localhost on a dual-stack machine, refuses to start (exit 1) and asks for an IP literal; a name with one address and every IP literal bind as before.
  • An If-Match or If-None-Match on a write an accessor verb serves is 400 invalid-input and the accessor does not run, instead of being ignored. An accessor-served GET (:get, :list) evaluates both headers against the sha256 ETag of its output (412, 304 including W/ forms, lists and *, 400 when malformed), ?meta= evaluates them after its gate, and an event-stream subscribe with either header is 400.
  • A verb-route action (POST /v1/<obj>:<action>) with an If-Match or If-None-Match is 400 invalid-input and does not run, and a verb-route function evaluates both headers against its output ETag in the same way.
  • A non-empty data-plane PUT with no Content-Type is refused 415 (invalid-input) and writes nothing; it was merged as JSON. Send application/json, or the value’s own media type for a binary value. A blank or malformed media type (a comma anywhere in the value, or not type/subtype) counts as none, and a PUT with more than one Content-Type line is refused 415 whatever the body.
  • RESTACT_MCP_ALLOW_NONLOOPBACK is a strict switch: only 1 or true (any case) lets a non-loopback RESTACT_MCP_LISTEN start, and any other value, an empty one included, exits 2 naming the variable.
  • The client plugin’s invoke.sh, discover.sh, deploy-verb.sh and mint-hs256-token.sh are removed. Its skills use restact and restactd token mint instead.
  • restact --json reports a usage error with clap’s whole message, so restact --json call names the missing <ROUTE>; the error: prefix and the usage and help hint are dropped.
  • The restact client moves to reqwest 0.13 with the rustls-no-provider TLS stack and the ring provider, as the host uses, so Cargo.lock carries one reqwest. An https:// target is verified against the operating system’s CA store (on Linux SSL_CERT_FILE and SSL_CERT_DIR replace it; a base image without root CAs needs ca-certificates) and an http:// target uses a client with no trust roots. An https client that cannot be built for want of roots names the fix. An http:// host that redirects to https is refused with a named error; configure the https URL.
  • Published event data is bounded in bytes: one event’s data, stamp included, is capped by RESTACT_EVENT_MAX_DATA_BYTES (64 KiB; over it event.publish answers 413), each topic’s replay ring, the durable log and one invocation’s published total by RESTACT_EVENT_RING_MAX_BYTES (4 MiB, oldest first), every topic’s ring together by RESTACT_EVENT_TOTAL_MAX_BYTES (64 MiB), a published topic by 1024 bytes, and a resume behind the retained events starts with a gap event on every backend, including after the topic was dropped or the PostgreSQL log pruned. A topic’s entry counts against the total, its broadcast channels exist only while someone subscribes (their memory is bounded by the stream cap), and a verb and the lifecycle hooks it fires share one invocation total. A PostgreSQL subscribe reads at most the newest 256 events within the ring budget, and the process-isolation parent reads a bounded worker reply. A verb’s over-cap object write now answers 413 like the data plane.
  • The example content that startup seeds (the demo verbs, the JavaScript and Python example verbs and their backing objects, the docs/<page> objects and the renderers) is off unless RESTACT_EXAMPLES=1, on every host including the container image. The scripting runners still register whenever built. make run, make docker-run and scripts/demo.sh set it. restactd audit ancestry follows the switch and lists a caller’s counters/<id> under the bootstrap counters object as host-bootstrap.
  • A JSON request body that repeats a member name at any depth is refused 400 invalid-input naming the member (data-plane PUT, verb policy, props and rollback, sub-token mint, grants, schedules, subscriptions, /admin/reown and POST /mcp). The check runs after authentication and before any authorization or lookup: an anonymous mutation on a host with auth configured is still 401 and its body is not parsed, and a disabled schedule or subscription surface still answers 501.
  • Invoking a stored verb that no longer links against the host answers 500 verb-unlinkable, naming the verb and the import, instead of a trap. The failure is remembered per component, the verb stays in discovery, and one verb-unlinkable: line per verb goes to stderr.
  • An upload that imports something the host does not provide is refused at deploy, at a code replace and at runner registration with 403 disallowed-import naming the import, and a component that links but lacks the world’s invoke export is refused with 400 invalid-component. Before, such an upload was stored and every call to it failed.
  • Requests to an http:// server no longer go through HTTP_PROXY, http_proxy, ALL_PROXY or all_proxy, for both the restact command and the MCP bridge, so a proxy never sees the bearer token in the clear. An https:// server keeps the proxy settings.
  • PUT with If-None-Match: * is a create-only write on objects (JSON, binary and the secrets mount), atomic under the object lock: an existing object returns 412. If-Match and If-None-Match on the data plane share one parser (400 when malformed, repeated lines combined), apply to GET, PUT and DELETE, and are evaluated after the authority check, so a caller who may not write or delete gets 403, never 412 or 400. A GET or DELETE precondition on an absent object is the plain 404, the secrets mount refuses an unsupported or malformed precondition on PUT and DELETE only after the authority check and leaves the secret in place, a coupled-mode DELETE checks bound-verb authority before the precondition, and If-Match: * means a current representation exists, so a write-only caller can use it. Every 405 carries an Allow header matching OPTIONS for the path, and a method on an undeployed verb is 404.
  • PostgreSQL subscription delivery is claimed through one cursor per subscription. A subscription is delivered or skipped at most once per event, in order, across the cluster; an event published before the subscription was registered is never delivered; and a node attempts only events published after it connected, so a restart delivers nothing published before it. Migration 0011_subscription_cursors.sql replaces the per-event claim markers, and nothing needs pruning.
  • The PostgreSQL subscription-claim state is one row per subscription, so it no longer grows with the event rate.

Fixed

Section titled “Fixed”
  • The restact mcp bridge returned structuredContent for any JSON body; it now does so only when the body is a JSON object, as MCP types it, and a string, array or number body keeps only the text block.
  • A secrets-mount slot never serves binary content, and a mediated write drops it.
  • The Python tier checks the arguments of obj and caller methods: a missing argument, a non-string, an extra positional or an unknown keyword raises invalid-input instead of acting on an empty string, and a method called on the wrong object (caller.get(...), obj.subject(), .get on a query row) raises AttributeError.
  • The Python tier checks the arguments of compose and publish the same way: compose(verb, input) and publish(topic, name, data) need a string verb, topic and name, input and data may be left out (they read as empty) but a given one must be a string. A missing or non-string argument, an extra positional or an unknown keyword raises invalid-input instead of calling the host with an empty string, and llm.complete refuses an extra argument the same way.
  • A verb’s set, set-at and set-at-if refuse a property name starting with @ with forbidden, as they already did for $.

Security

Section titled “Security”
  • With the built-in site on, the repo_doc fallback refuses a symlink that resolves outside the served directory it was requested under (docs/, openapi/, examples/, conformance/ or wit/). Before, a symlink inside docs/ could serve any documentation-type file elsewhere in the working directory, such as Cargo.toml. A served directory that is itself a symlink out of the working directory, or to the working directory itself, is refused.
  • wasmtime 50.0.1 fixes a host memory exhaustion a guest could trigger: a component that passed borrows of its own resources between nested components made the host allocate memory that no limit counted (RUSTSEC-2026-0424). The three other advisories fixed in that release do not reach restactd: the wasip3 UDP policy race (verbs get no network and only WASI preview 2 is linked) and two GC type issues (GC is off).
