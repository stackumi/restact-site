Tutorial: build a small app

You will build a link shelf: a shared collection of bookmarks that two users add to, click through and search. Along the way you store object data, write verbs that act on it, query a collection, turn on authentication so callers cannot overwrite each other, and react to new links with a lifecycle hook. Plan on about 30 minutes.

You need a running restactd with the JavaScript runner (see Install) and curl. If you have not yet deployed a verb, do the Quickstart first.

1. Start a host with authentication

Section titled “1. Start a host with authentication”

A shared app needs to know who is calling. Start the host with a signing secret for HS256 bearer tokens and a data directory, from the repository root:

That secret is a placeholder. For anything beyond this walkthrough, generate one with openssl rand -base64 32; the host refuses to start with a secret shorter than 32 bytes.

Two things change when authentication is on. Anonymous callers can read but cannot deploy verbs or write data, and the host defaults to strict object binding, which means you must create an object before you deploy a verb on it. The tutorial uses both.

Every deploy answers 201 Created with a small JSON object (verb, kind, sha256, imports), which the tutorial does not repeat.

A new verb is private to its owner. exec=public lets anyone call it. Normally a verb runs with its caller’s authority and so cannot write an object the caller does not own, which would stop Bob from bumping Alice’s counter. runs_as=owner makes this one verb run with its owner’s authority instead. That is a deliberate widening you opt into per verb; the default stays run-as-the-caller.

orderBy and predicate run in the store. A page holds at most 1000 objects, and a longer result carries a cursor to pass back as cursor in the next call. With this many links one page is enough.

Tip

Name verbs that are not accessors with care. get, list, set, create, update and delete are reserved names that the host dispatches on plain reads and writes of an object. That is why this verb is search, not list.
