restactd

Upload a small sandboxed program, call it at a URL.
QuickstartRead the concepts

restactd is the reference server for REST:ACT. Clients deploy verbs, short programs in JavaScript, Python or any language that compiles to WebAssembly, and call them with GET and POST. Each call runs in a sandbox under compute, time and memory limits, with only the access it was granted and only the authority of its caller.

Build restactd and the JavaScript runner first: see Install.
