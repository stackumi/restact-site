WIT interfaces

Every verb is a WebAssembly component that targets one world of the WIT package rest-act:plugin@0.1.0. The world a verb targets lists the only host functions it can call, so it doubles as the verb’s capability manifest.

The package lives in wit/. Check it with wasm-tools component wit wit/.

Worlds

Section titled “Worlds”

A world imports interfaces and exports one function, invoke. A host links only the imports a component declares, so a verb that does not import compose cannot reach it.

WorldImportsUse
pluginhostThe minimal verb: structured logging only.
plugin-composehost, composeCalls other verbs.
plugin-identityhost, identityReads who is calling.
plugin-objecthost, object, identityReads and writes the data of its object.
plugin-object-composehost, compose, object, identityObject data and composition.
plugin-object-eventhost, object, identity, eventObject data and event publishing.
plugin-object-compose-eventhost, compose, object, identity, eventObject data, composition and events.
plugin-llmhost, llmModel completions only.
plugin-object-llmhost, object, identity, llmObject data and model completions.
plugin-object-compose-event-llmhost, compose, object, identity, event, llmEverything above. The reference host binds this world, so it can instantiate a verb built against any of the others.

No world offers wasi:sockets, and wasi:filesystem is linked with no directories, so a verb has nothing to read or write. Outbound network access goes through the host, not through the guest; see Outbound calls and secrets.

The entry point

Section titled “The entry point”

Every world exports the same function.

payload is list<u8>. The HTTP layer carries the encoding, which is JSON by default. An invocation-error has a stable code and a human-readable message; the host maps the code to an HTTP status and a problem document. See Errors and status codes.

Interfaces

Section titled “Interfaces”

host

Section titled “host”

Ambient: every verb gets it.

FunctionMeaning
log(level, message)Emit a log record. Levels are trace, debug, info, warn, error. Rate-limited per tenant.

compose

Section titled “compose”

Gated by the plugin-compose family of worlds, and by the call graph declared at deploy time with ?calls=.

FunctionMeaning
invoke(verb, input)Call another verb by route id, for example docs:wordCount. The callee runs as the same caller (or as its owner, when it was deployed with runs_as=owner) and draws from the same budget.

See Compose verbs.

object

Section titled “object”

Gated. Reads and writes the data properties of the object the verb is bound to, and of other objects by path. Every call is checked against the caller’s access, so a verb never reads or writes what its caller could not.

FunctionMeaningFeature
get(name)Read a property of the bound object. none when absent or not readable.object-data-access
set(name, value)Write a property of the bound object. Buffered and merged only if the invocation succeeds.object-data-access
get-at(path, name)Read a property of another object.object-data-access
set-at(path, name, value)Write a property of another object. Allowed only if the caller could write it through the data plane.object-data-access
remove(name)Remove a property of the bound object, under the authority set needs. Removing an unset property succeeds; not-found when the bound object holds no data. Buffered and applied only if the invocation succeeds.object-remove
remove-at(path, name)Remove a property of another object. Allowed only if the caller could remove it through the data plane. not-found when no object is stored at path.object-remove
set-at-if(path, name, value, expected)Write only if the current value equals expected (none means absent). Atomic compare-and-swap.object-cas
shape() / shape-at(path)List readable property names, readable child paths and invokable verb names.object-data-access
get-bytes() / get-bytes-at(path)Read a stored binary value as a content type and bytes.object-binary
query(prefix, order-by, descending, predicate, limit, cursor)One ordered, access-filtered, cursor-paginated page of objects under a path prefix. The host caps limit.verb-object-query
path()The concrete path of the object the verb was invoked on, not the route pattern it is deployed at. none for an unbound verb.object-self-path

A property value is a property-value variant (feature typed-values): text(string) for a JSON string, carried raw, and json(string) for any other JSON value as JSON text, which the host emits in RFC 8785 canonical form. A stored string reads as text; anything else reads as json. On a write, json must parse and a number whose value is a whole number must lie within ±(2^53−1) (so 1e21 is refused) and nesting is bounded at 64 levels, else invalid-input; json("null") is refused with invalid-input (a stored property is never null); a json payload that parses to a string is stored as that string; the host folds integral doubles to integers and -0 to 0. set-at-if compares stored forms: text byte for byte, json by canonical form, and a text never equals a json. A query row’s properties and order-value carry property-value too: the order value is text for a string, an absent property (text("")) or the path, and json otherwise.

set-at-if is refused under the atomic-invocation consistency level, and the host stops advertising object-cas at that level. See Store and query object data and the features table.

identity

Section titled “identity”

Ambient except for invoker. A verb already runs as its caller, so reading the caller grants no new authority.

FunctionMeaningFeature
subject()The authenticated subject, or none when anonymous.caller-identity
is-anonymous()True when there is no subject.caller-identity
roles()The caller’s roles.caller-identity
scopes()The caller’s scopes.caller-identity
groups()The caller’s group memberships.caller-groups
claim(name)One scalar token claim, stringified, or none.caller-identity
invoker()The subject on whose behalf an authority-switched invocation tree runs. none unless the verb was deployed with ?invoker=1.identity-invoker
actor()The delegation actor that bounds this frame, or none. Never reveals the delegating subject.identity-actor

See Identity and authority.

event

Section titled “event”

Gated.

FunctionMeaning
publish(topic, name, data)Publish an event on a topic, which is an object path. Subscribers receive it over Server-Sent Events. The name is 1-128 bytes with no ASCII control characters; anything else is refused with invalid-input. A function verb cannot publish.

Needs event-subscriptions. See Schedules and subscriptions.

llm

Section titled “llm”

Gated. Present only in the plugin-llm, plugin-object-llm and plugin-object-compose-event-llm worlds.

FunctionMeaning
complete(req)One bounded, synchronous, text-only model completion through a connector object. Returns the text, a stop reason, the model that answered and token usage.

A completion request names the connector path, an optional system prompt, a list of role/content messages, and optionally a model, an output-token limit and a temperature. complete has side effects, so deploy refuses a function verb that imports it. It is also refused under process isolation. Needs llm-connector. See Outbound calls and secrets.

Stability

Section titled “Stability”

The package is 0.1.0 and is not frozen yet. It freezes at outside adoption: the first public release, or earlier if the maintainer declares it. Until then a change to any file under wit/ needs the maintainer’s approval, and a change to an existing declaration lands together with every component built against the package. After the freeze world.wit (types, host, compose, and the plugin and plugin-compose worlds) is not edited at all, so components compiled then keep linking. A breaking change after the freeze means a new package version.

New capabilities, before and after the freeze, arrive as additions in the same package 0.1.0, each behind its own feature token: a new interface in its own file, a new world that includes an existing one, or a new method on an existing interface outside world.wit. Adding an import never breaks an existing component, because the host binds the superset world.

A component that imports a newer method cannot link on a host that predates it. For that reason each such method has its own feature token in discovery, and a client checks for the token before deploying a verb that needs the method. The host checks linking at deploy: an upload that imports something the host does not provide is refused with 403 disallowed-import naming the import, and a component that links but lacks the world’s invoke export is refused with 400 invalid-component naming the export. Nothing is stored for a refused upload.

Choose the smallest world that covers what your verb does. The deploy step rejects a component that imports something outside the host’s allow-list or that the host does not provide, and llm when llm-connector is not enabled. A grant withheld from a verb, such as ?object=deny, is not checked at deploy; it is enforced at call time.
