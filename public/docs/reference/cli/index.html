The restact command line

restact is the client for any REST:ACT server. It reads the server’s discovery document, builds the URL for you, and turns the server’s answer into an exit code. It never expands braces in a route, so items/{id}:get needs no curl -g. The server side is restactd, which has its own commands (see Configuration and Operate).

Global flags

Section titled “Global flags”

These work on every command.

FlagMeaning
--url URLThe server for this command only. No stored token is sent.
--context NAMEUse this named context.
--json[=BOOL]Print one JSON document on stdout. A failure prints {"error": {"exit": N, "message": "..."}}, with status and problem added when the server answered. events tail prints one JSON event per line.
-v, --verboseLog each request line and response status on stderr. The token is never logged.
--timeout SECSWhole-request timeout, 30 by default. For events tail it is the idle timeout.
--max-bytes NLargest body, 64 MiB by default. It caps request bodies, response bodies and the total of a listing.

Deploy

Section titled “Deploy”

The language comes from the file extension: .wasm is a compiled component, .js is text/javascript, .py is text/x-python. Source files are checked against the server’s accepted languages first, and a server that does not take that language gives exit 3. Any other extension is a usage error.

OptionMeaning
--kind function|actionLeft out, the server’s default applies.
--calls ROUTE:VERBA verb this one composes. Repeat it or separate the values with commas.
--produces TYPE, --description TEXTThe output media type, and a description for people and models.
--input-schema FILE, --output-schema FILEA JSON Schema file for the verb’s input or output, sent compact as input_schema/output_schema. The file is read and parsed first (subject to --max-bytes; not JSON is exit 2). A server that does not advertise verb-schemas is refused with exit 3. Not allowed with --update.
--exec public|ownerWho may invoke the verb. The default is owner.
--deny CAPWithhold a capability: object, compose, event or llm. Repeatable.
--fuel N, --mem-mb N, --wall-ms NPer-call limits.
--runs-as ownerRun with the owner’s authority.
--lib FILEPut a library file in front of a .js or .py source. Repeatable; each file is followed by a newline.
--updateReplace the code of an existing verb.
--create-onlyFail with 412 if the verb already exists. The server must advertise verb-conditional-requests.

--update and --create-only cannot be combined, and --update replaces only the code, so it refuses the descriptor options (--kind through --runs-as) with exit 2. --lib still applies. A route with {id} is passed as written.

Call

Section titled “Call”

The method comes from the server’s discovery document, matched against the route the way a client would. A host lists a verb in discovery only to a caller who may read or invoke it, so a route missing from the listing may still be deployed. For such a route the command sends a credential-free OPTIONS and reads Allow: GET means a function and POST an action, and the call then goes out with your token, so a caller who may not use the verb gets the host’s own 401 or 403 (exit 4). A 404 to the probe is a not-found failure (exit 1). When the probe gives no single kind (a 405, 501 or an Allow naming both) or discovery lists the route with conflicting kinds, the command stops with exit 2 and asks for --get or --post; either flag skips the probe. A GET takes no body: pass parameters with --query K=V. For an action, the input is --input TEXT, --input-file FILE, or - for stdin. --accept TYPE and --idempotency-key KEY set the matching headers, and -o FILE writes the response body to a file.

When stdout is piped or redirected, the response body goes out byte for byte, with no newline added. On a terminal, control characters are replaced, a newline is added if the body lacks one, and a binary body is refused unless you give -o.

Objects

Section titled “Objects”

put takes its type from --content-type; without it, a .json file is application/json and anything else is application/octet-stream. rm asks for confirmation on a terminal and needs --yes everywhere else. ls objects needs the server to advertise object-listing, --prefix also needs object-listing-prefix, and --filter needs object-query; otherwise the command exits 3.

Choosing the server

Section titled “Choosing the server”

The target comes from the first of these that is set:

  1. --url
  2. --context
  3. RESTACT_URL
  4. RESTACT_CONTEXT
  5. the config file’s current-context
  6. http://127.0.0.1:8080, which gets no environment token (RESTACT_TOKEN, RESTACT_MCP_BEARER); restact mcp with RESTACT_MCP_LISTEN refuses to start on it

A context is a name for a URL, with an optional stored token:

Contexts live in config.toml, at $RESTACT_CONFIG if that is set, else $XDG_CONFIG_HOME/restact/config.toml, else ~/.config/restact/config.toml (on macOS too). The tokens live in credentials.toml in the same directory, created with mode 0600. The directory is created 0700. There is no config file inside a project directory, so a cloned repository cannot point the CLI at another server.

Tokens

Section titled “Tokens”

A token comes from RESTACT_TOKEN first, then from the stored token of the selected context. There is no --token flag, because command-line arguments are visible to every local user.

  • An environment token goes only to a server someone chose. When nothing names one (no --url, --context, RESTACT_URL, RESTACT_CONTEXT or current context), the built-in http://127.0.0.1:8080 gets no RESTACT_TOKEN: another local process may be listening there. The command runs without a token and prints one line on stderr naming RESTACT_TOKEN and saying to set RESTACT_URL. Writing --url http://127.0.0.1:8080 or RESTACT_URL=http://127.0.0.1:8080 is a chosen server and gets the token.
  • A stored token goes only to its own context’s URL. With --url or RESTACT_URL, only RESTACT_TOKEN is used, so restact --url https://other.example get x cannot leak the current context’s token.
  • The CLI refuses to send a token over plain http:// to a host that is not loopback (localhost, 127.0.0.0/8, [::1]). The refusal is exit 2. A context sets allow-plaintext = true (or context add --allow-plaintext) to accept the risk for that server.
  • credentials.toml is refused (exit 2) when other users can read or change it, when another user owns it, or when it is a symlink.
  • When a token would be sent to a URL that came from the config file, the config file must belong to you or to root and must not be writable by group or others. Otherwise whoever can edit it could redirect your token. The refusal is exit 2 and names the chmod to run.
  • Redirects are not followed. A 3xx is reported with its Location and exits 1.
  • A token is never printed. context show says token: stored, and -v leaves out the Authorization header.

Exit codes

Section titled “Exit codes”
CodeMeaning
0Success.
1The server refused or failed the request (4xx or 5xx not listed below), or a 3xx was not followed. A verb that answers with an error also exits 1.
2Usage or local configuration error: a bad flag, a bad config file, an unsafe credentials file, a refused plaintext token, a missing --yes.
3The server does not support what you asked: a required feature is not advertised, a 501, or a 404/405 where absence is not proof (deploy, verb properties), or a source language the server does not accept.
4Authentication or authorization: 401 or 403.
5Transport: connect, TLS, timeout, a response over --max-bytes, or an unreadable response. A request body over --max-bytes (put, deploy --lib, stdin) is a usage error, exit 2.
130Interrupted.

The server’s problem document is printed on stderr, or inside the --json error object.

Environment variables

Section titled “Environment variables”

The client reads these. The server’s own RESTACT_* variables are in Configuration; the two sets share no name.

VariableMeaning
RESTACT_URLServer URL, below --url and --context in precedence. A target set this way gets no stored token.
RESTACT_TOKENBearer token. Beats the stored token. Not sent to the built-in default http://127.0.0.1:8080; set RESTACT_URL to send it.
RESTACT_CONTEXTContext name, below --url, --context and RESTACT_URL.
RESTACT_CONFIGPath of config.toml. credentials.toml sits next to it.
RESTACT_MCP_*The bridge’s settings, listed in the bridge README.

restactd reads none of these. The one similar name restactd reads is RESTACT_MCP (exactly that name), which switches on the server’s own MCP facet and is documented in Configuration. restactd checkpoint takes its bearer from --token-stdin, never from RESTACT_TOKEN.

restact mcp

Section titled “restact mcp”

restact mcp runs the MCP bridge: it serves MCP over stdio, or Streamable HTTP when RESTACT_MCP_LISTEN is set, and turns a REST:ACT server’s verbs into MCP tools. It takes --url and --context like every other command. When RESTACT_MCP_HOST_URL and RESTACT_MCP_HOSTS are unset, the bridge uses the selected context’s URL and its stored token. Under RESTACT_MCP_LISTEN the context supplies the URL only, because a token there would become the identity of every client that connects without its own. Every other RESTACT_MCP_* setting is described in the bridge README.

The bridge checks its configuration before it serves anything. A bad target URL, listen address, number, switch or local OpenAPI file exits 2 with nothing on stdout, and a message that never repeats a credential. The five switches (RESTACT_MCP_ALLOW_PLAINTEXT, RESTACT_MCP_ALLOW_DEPLOY, RESTACT_MCP_ALLOW_DATA_WRITES, RESTACT_MCP_ALLOW_VERB_ADMIN, RESTACT_MCP_ALLOW_REGISTRATIONS) take 1, true, on or yes to turn on and 0, false, off or no to turn off, in any case; any other value is an error. RESTACT_MCP_FILE_ROOT is not checked at startup.

Each log and warning line the bridge writes to stderr starts with restact mcp:. A bridge refusal prints restact mcp: <reason> and exits with the CLI’s usual code, like every other command. The bridge ignores the global --json, --timeout and --max-bytes: stdout is the MCP wire, and RESTACT_MCP_REQUEST_TIMEOUT_SECS sets the request timeout.

The MCP server still reports its name as restact-mcp, and the restact-mcp: resource URIs keep that prefix.
