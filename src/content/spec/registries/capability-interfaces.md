# REST:ACT Capability Interfaces registry

A *capability interface* is a host interface a verb's WebAssembly component may import. A verb has
**no ambient authority**: any interface it does not import is unreachable (draft §Capability Model,
[ADR-0009](https://github.com/stackumi/restactd/blob/main/spec/decisions/0009-layered-capability-interfaces.md)). This registry names the standard
interfaces; on upload a server MUST reject a component importing an interface it does not permit or
does not implement (`403`, `restact_code=disallowed-import`).

- Registration policy: **Specification Required** (see [`README.md`](README.md)).
- Identifiers are WIT interface ids of the form `namespace:package/interface` with an OPTIONAL
  `@major.minor.patch` version suffix.
- The `rest-act:plugin@0.1.0` package in [`wit/`](https://github.com/stackumi/restactd/tree/main/wit) is the
  normative source for the v1 entries below. Each interface has its own file there, and the base
  worlds are in the frozen `wit/world.wit`. The `x-restact-verb.capabilities.interfaces` field
  references this registry.

## Registered interfaces (v1)

| Interface | World | Authority granted | Status | Reference |
|---|---|---|---|---|
| `rest-act:plugin/host` | `plugin`, `plugin-compose` | Structured logging (`log`) only. The minimal ambient capability granted to every verb. | provisional | `wit/host.wit`; draft §Capability Model |
| `rest-act:plugin/compose` | `plugin-compose`, `plugin-object-compose` | Invoke another verb (`invoke`). **Gated**: linked only for components targeting a compose world, and enforced at runtime against the declared call graph, shared budget, depth/fan-out/cycle bounds, and authority attenuation (draft §Composition). | provisional | `wit/compose.wit`; draft §Composition |
| `rest-act:plugin/object` | `plugin-object`, `plugin-object-compose` | Object-graph data access: read (`get`) / write (`set`) the bound object's declared data properties, read another object's by path (`get-at`), **write another object's by path (`set-at` — cross-object write-policy intersection)**, **conditionally write a property by compare-and-swap (`set-at-if` — write iff the property's current committed value equals an expected value, atomic under the object write lock, `precondition-failed` on mismatch, and without comparing for a principal who may not read the property of an existing object; ADR-0061, feature `object-cas`)**, **introspect an object's shape (`shape`/`shape-at`: readable properties + readable direct children + invokable verbs)**, and **read a PAGE of objects under a path prefix (`query` — ordered, optionally equality-filtered, ACL-filtered, keyset-paginated, with a host-enforced per-call page cap; ADR-0071, feature `verb-object-query`)**, and **learn the CONCRETE path of the object it is bound to (`path` — the invoked object, never the deployed route pattern; `none` for an `unbound` verb; a pure read, so `function` verbs may call it; ADR-0080, feature `object-self-path`)**, and **write the caller's real subject as a property's value (`set-subject`/`set-subject-at` — authorized exactly as `set`/`set-at`, `forbidden` for the anonymous principal, so a verb given a pairwise subject can name its caller for a `prop:` matcher; actions only; feature `object-set-subject`)**, and **remove a property of the bound object or of another object by path (`remove`/`remove-at` — authorized exactly as `set`/`set-at` of the same name; a set `final` property and the `$` namespace are refused, a property that is not set is left alone, and `remove-at` never creates an object; actions only; ADR-0127, feature `object-remove`)**, and **read and write an object's binary value (`get-bytes`/`get-bytes-at`, gated by the object's `read` policy, feature `object-binary`; `set-bytes`/`set-bytes-at`, authorized as a binary `PUT` of the object, actions only, feature `object-binary-write`; ADR-0053)** — ACL- and scope-aware (`instance`/`shared`, `final`). A value is a `property-value` (`text(string)` or `json(string)`, ADR-0136, feature `typed-values`) on `get`/`set`/`get-at`/`set-at`/`set-at-if` and in the `query` row's `properties` and `order-value`; `query-cursor.order-value` and `predicate` stay strings. **Gated**: linked only for components targeting an object world, enforced at runtime against the per-property ACL (vs. the runs-as-caller principal) and capability attenuation (ADR-0023, ADR-0033, ADR-0053, ADR-0061, ADR-0071, ADR-0080, ADR-0127). | provisional | `wit/object.wit`; [draft-byrd-restact-objects-00](../draft-byrd-restact-objects-00.md) §Object Data Access |
| `rest-act:plugin/identity` | `plugin-identity`, `plugin-object`, `plugin-object-compose` | Read-only view of the runs-as-caller principal: `subject`, `is-anonymous`, `roles`, `scopes`, `claim(name)`, plus the separately advertised `subject-kind` (feature `identity-subject-kind`), `groups` (feature `caller-groups`), `invoker` (feature `identity-invoker`, which needs a grant at deploy) and `actor` (feature `identity-actor`). **Ambient** (like `host`): linked with no grant, no attenuation, and no ACL — it reveals no authority the verb does not already hold, since it runs *as* this caller (ADR-0027). Every subject it returns is pairwise, `actor` returns the string `delegated` for every actor, and `claim` returns none except for claims the operator lists, unless the server advertises `identity-real`. Imported per-verb, so it still appears in the manifest. | provisional | `wit/identity.wit`; draft §Caller Identity |
| `rest-act:plugin/llm` | `plugin-llm`, `plugin-object-llm`, `plugin-object-compose-event-llm` | One bounded, synchronous, text-only model completion (`complete`) through a `kind:"llm"` connector object named by path, carrying its own explicit `$policy` (`read` in that list is the use-grant; an inherited tier never is). **Gated** like `compose`/`object`/`event`; **effectful** (actions only; deploy refuses a `function` importing it); host-capped per invocation tree; the wire protocol is a registered, versioned `provider` row ([`llm-providers.md`](llm-providers.md)); credential spliced host-side in the server process only (ADR-0094, never guest-visible; refused under process isolation in v1); reserve-then-reconcile against the connector's budget root as the budget's owner through the ordinary policy gate ([ADR-0095](https://github.com/stackumi/restactd/blob/main/spec/decisions/0095-typed-connectors-llm.md); feature `llm-connector`). | provisional | `wit/llm.wit`; [draft-byrd-restact-connectors-00](../draft-byrd-restact-connectors-00.md) §Model Completion |
| `rest-act:plugin/webhook` | `plugin-webhook`, `plugin-object-webhook`, `plugin-object-compose-event-llm-webhook` | One signed JSON `POST` (`post`) through a `kind:"webhook"` connector object named by path, carrying its own explicit `$policy` (`read` in that list is the use-grant; an inherited tier never is). The owner fixes the destination and request path; the host fixes the method, content type and header fields and signs with the Standard Webhooks scheme, the key resolved host-side only. Returns only the status. **Gated** like `compose`/`object`/`event`/`llm`; **effectful** (actions only; deploy refuses a `function` importing it); at most 8 calls per invocation tree; at most once, never retried by the host (feature `webhook-connector`). | provisional | `wit/webhook.wit` (pending); [draft-byrd-restact-connectors-00](../draft-byrd-restact-connectors-00.md) §Webhook Delivery |
| `rest-act:plugin/event` | `plugin-object-event`, `plugin-object-compose-event`, `plugin-object-compose-event-llm`, `plugin-object-compose-event-llm-webhook` | Publish events to a topic (`publish(topic, name, data)`), gated; SSE delivery + lifecycle hooks consume them (ADR-0039, feature `event-subscriptions`). Reserved within the interface: a guest-readable subscription/schedule binding API. | provisional | `wit/event.wit`; [draft-byrd-restact-events-00](../draft-byrd-restact-events-00.md) §Publishing events |
| `rest-act:plugin/types` | all | No functions; shared type definitions (`payload`, `invocation-error`, `log-level`). Not authority-granting. | provisional | `wit/types.wit`; draft §Guest Contract |

## Reserved / planned

The following interfaces are reserved for later versions and are added here as separate,
individually-gated interfaces so that a verb's imported set remains an exact, auditable capability
manifest. A reserved interface is **not yet** part of `rest-act:plugin@0.1.0`; when one ships it is
added **additively within** the same frozen package (the `object`/`identity`/`event` idiom —
`world.wit` byte-unchanged, a new `*.wit` file and new worlds), and its row moves to the table above.

| Interface (planned) | Intended authority | Status |
|---|---|---|
| `rest-act:plugin/kv` | Scoped key-value storage. | reserved |
| `rest-act:plugin/request` | Read the request that started the frame: `method` and `header(name)` for the request header fields the verb declared at deployment, within the server's ceiling and outside its fixed deny; only the root frame of a route entry sees header fields. Worlds: `plugin-http-handler`, `plugin-object-http-handler`, `plugin-object-compose-event-http-handler` and the superset `plugin-object-compose-event-llm-http-handler`; a verb of another combination builds against the smallest of these that includes it, and its descriptor names its base world with those of `request` and `response` it imports in `interfaces`. Feature `verb-http-handler`; [draft-byrd-restact-http-verbs-00](../draft-byrd-restact-http-verbs-00.md) §The guest contract. | reserved |
| `rest-act:plugin/response` | Set the verb's own response: `set-status` (a fixed per-kind set), `set-header` (`Content-Disposition`, `Cache-Control`, `Content-Language`, `Location` only) and `set-content-type` (the verb's declared types). Same worlds and feature as `request`; [draft-byrd-restact-http-verbs-00](../draft-byrd-restact-http-verbs-00.md) §Response control. | reserved |
| `rest-act:plugin/egress` | **Re-dispositioned as a framework name, not an interface** ([ADR-0095](https://github.com/stackumi/restactd/blob/main/spec/decisions/0095-typed-connectors-llm.md) D1): no interface named `egress` will ship, and verb-callable allow-listed raw HTTP is withdrawn as a planned authority. The name denotes the *typed-connector framework* — a family of individually gated interfaces (one per kind of outside thing), each executed by the host through a governed connector object with `read` as the use-grant, the ADR-0094 egress rules, a host-known purity class, and a metering tier. A framework name, not a linkable interface — it never leaves this table. Members: `rest-act:plugin/llm` and `rest-act:plugin/webhook`, registered above. | reserved |

> Implementation note: the reference host's upload allow-list (`ALLOWED_IMPORT_PREFIXES` in
> [`host/src/wasm_exec.rs`](https://github.com/stackumi/restactd/blob/main/host/src/wasm_exec.rs)) permits `rest-act:plugin/` plus the authority-free WASI interfaces Rust's
> std pulls in (linked but populated empty). Authority-granting WASI interfaces (`wasi:sockets`,
> `wasi:http`, real `wasi:filesystem`) are absent, so a component importing them is rejected.
